# 🃏 Дурак Онлайн 3D — Полная документация

> **VK App ID**: `54720415`  
> **Инфраструктура**: Railway / Docker / Node.js + Socket.IO  
> **3D Движок**: Three.js WebGL / Procedural Shaders / WebAudio API

---

## 🌟 Что реализовано в проекте

### 1. 🎮 Игровой движок (Server)
- **Режимы игры**:
  - `Подкидной Дурак` — классический режим с возможностью подкидывания карт всеми участниками.
  - `Переводной Дурак` — перевод хода на соседа картой того же достоинства с проверкой лимита карт на руках у следующего игрока.
- **Поддержка 2 – 6 игроков** за одним столом.
- **Размеры колод**: 24, 36, 52 карты.
- **Тонкие правила**: лимит 5 карт в первом отбое партии, очередь хода по часовой стрелке, правильный добор карт (атакующий -> подкидывающие -> защитник).
- **Анти-чит архитектура**: сервер отправляет каждому клиенту *только его собственные карты*. Карты соперников скрыты до момента их выкладывания на стол.
- **ИИ Боты**: возможность автозаполнения мест ботами для мгновенного старта или соло-тренировки.

### 2. 💎 3D Визуализация (Client Three.js)
- **Физический стол**: 8-угольный стол из красного дерева с латунными вставками и сукном с микроворсом.
- **Процедурная адаптивная камера**: автоматически перестраивает ракурс и угол наклона под 2, 3, 4, 5 или 6 игроков.
- **Интерактивный веер карт**: карты раскладываются в руке веером с тактильным подъемом при наведении и поддержкой Drag & Drop на стол.
- **Анимации полета по кривым Безье**: реалистичный бросок карт, отбой, взятие и сбор в биту.
- **Интерактивные 3D броски предметов**: возможность бросить в оппонента помидор 🍅, открыть бутылку шампанского 🍾 или бросить монеты 🪙 с частицами брызг и звуком!

### 3. 📱 VK Mini App Интеграция & Шеринг
- Авторизация через `@vkontakte/vk-bridge` (App ID `54720415`).
- **Стильный вирусный шеринг**: автоматический рендер эстетичной карточки победы высокого разрешения (1080x1920) на Canvas с матовым стеклом (Glassmorphism) для **VK Историй** (`VKWebAppShowStoryBox`) и **стены VK** (`VKWebAppPostToWall`).
- **Тактильный отклик**: Taptic Engine виброотклик на ключевых действиях.
- **VK Pay**: готовые хуки оплаты наборов фишек и золота.

### 4. 🔊 Процедурный 3D Звуковой движок (Web Audio API)
- Реалистичный бархатный шелест скольжения карт по сукну.
- Хлопок карты при приземлении на стол.
- Звон фишек, хлопок пробки шампанского, брызги помидора и победный аккорд без необходимости скачивать тяжелые mp3 файлы.

## 🚀 Как запустить локально

В терминале проекта выполнить:
```bash
npm start
```
Сервер запустится на `http://localhost:3000`.

---

## ☁️ Деплой на Railway за 1 минуту

1. В личном кабинете [Railway.app](https://railway.app) нажмите **«New Project» -> «Deploy from GitHub repo»**.
2. Выберите репозиторий с проектом.
3. Railway автоматически распознает `Dockerfile` и `railway.json` и запустит контейнер.
4. В разделе **Settings -> Generate Domain** скопируйте предоставленный HTTPS-URL.

## 🔗 Подключение к VK Mini Apps (App ID `54720415`)

1. Откройте консоль разработчика [vk.com/apps?act=manage](https://vk.com/apps?act=manage) и выберите приложение **54720415**.
2. В разделе **Настройки**:
   - **URL для Web / Мобильных**: укажите URL вашего сервиса на Railway.
3. Готово! Игра будет открываться в VK на ПК, iOS и Android.
